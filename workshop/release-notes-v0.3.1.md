Download **[rps-event-kit.zip](https://github.com/Eastbridge-Academy/rps-client-kit/releases/download/v0.3.1/rps-event-kit.zip)**
and extract it. The kit includes its dependencies and printable handouts;
participants do not need to clone a repository or build anything.

Start with **[00-setup.pdf](https://github.com/Eastbridge-Academy/rps-client-kit/releases/download/v0.3.1/00-setup.pdf)**,
which covers lab machines, personal laptops on macOS/Linux and Windows,
submission, and local practice. The [README](https://github.com/Eastbridge-Academy/rps-client-kit/blob/v0.3.1/README.md#on-your-own-laptop)
has the same installation commands as selectable text. Install uv and Python
once; kit installation and practice then work from the downloaded files.
The facilitator supplies the event token.

## Handouts

Print setup in its own pile. Choose one level; each starts with randomness and
prediction, explains the bot API, then goes into its exercises.

- **00 Setup and practice:** 4 pages, including personal-laptop installation.
- **01 Beginner:** 5 pages, simple patterns and reactive bots.
- **02 Intermediate:** 6 pages, frequencies and recent windows.
- **03 Advanced:** 6 pages, Markov models and backoff.
- **04 Expert:** 7 pages, strategy portfolios and end-of-match decisions.
- **05 Meet the house bots:** 2 landscape pages, all 16 opponents and hints.
- **06 Facilitator notes:** 3 pages, schedule, preparation and worked answers.

The handouts are now authored directly in LaTeX. Numbered Python listings have
an internal gutter so line numbers clear the yellow box's border. The seven
PDFs contain 33 pages; setup instructions no longer repeat in every level.
The SDK and bot behavior are unchanged from 0.3.0.
